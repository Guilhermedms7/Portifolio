# Portfólio — Guilherme Damasceno Oliveira

Site pessoal de Guilherme Damasceno, Desenvolvedor Full Stack na Develcode. O portfólio apresenta minha experiência com sistemas corporativos, desenvolvimento de APIs, integração entre serviços, modernização de sistemas e automação, além de projetos, formação e formas de contato.

Sou formado em Análise e Desenvolvimento de Sistemas pela Universidade de Sorocaba (UNISO) e curso Engenharia de Software na Estácio. Trabalho principalmente com Java e Spring Boot, C# e .NET, e também uso React.js, Python, JavaScript e n8n em projetos e integrações.
